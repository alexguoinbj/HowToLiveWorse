# 被裁之后，如何让手续更难办

![离职篇：先签字，后算账](../assets/illustrations/job-loss.svg)

> 本文用反讽写办事误区，不嘲笑失业的人。「反向做法」不是建议。劳动争议、保险和救助政策因事实、地区和时间而异；有疑问时尽快向当地人社部门、法律援助机构或律师核实。

## 当天：把签字变成速度比赛

**反向做法：** 公司递来写着「个人原因辞职」的文件，先签再说；补偿只靠口头承诺，自己参加的谈话和离职文件也不留记录。

**隐藏成本：** 离职原因、补偿条件和双方实际约定可能难以证明，部分权益也可能受到影响。

**翻过来：** 签字前看清离职原因、补偿金额、支付时间及其他条款；文件内容与事实不符时，不要为了赶流程签字。不理解的内容先询问或咨询专业人士，签署后保留一份文件。依法保存与自己劳动关系有关的合同、工资、考勤、社保及沟通记录。交接时保护公司数据，不擅自带走源码、客户资料或破坏系统。

## 头几天：只看到账金额，不看账目

**反向做法：** 不问解除原因，也不核对工资、奖金、补偿、未休年假或加班费。公司说数字已经算好，就不需要明细。

**隐藏成本：** 不同解除情形和个人工资记录可能影响应付项目及计算方式；口头数字可能遗漏争议。

**翻过来：** 请对方提供结算明细，结合合同、工资和工作记录核对各项。经济补偿、额外通知期工资或赔偿是否适用，取决于具体事实和法律规定；有争议时咨询法律援助或律师。

## 头一周：把保障和竞业都放在记忆里

**反向做法：** 不查失业登记、失业保险、医保接续，也不保留竞业协议和补偿记录。每天只做一件事：刷新招聘网站直到凌晨。

**隐藏成本：** 可能错过申请或接续安排，也不清楚竞业义务和补偿是否得到履行。

**翻过来：** 通过当地公共就业服务、人社和医保渠道核实登记、待遇和办理期限；保存竞业协议与付款记录。为求职和休息留出可维持的时间，必要时请可信的人陪伴。

## 头一个月：把求职和维权交给广告

**反向做法：** 欠薪不留证也不查时效；有人说「交钱培训、包你上岗」，就立刻借钱报名。公益就业服务、培训补贴和就业困难人员支持一概不问。

**隐藏成本：** 劳动争议可能有申请时限，求职诈骗或高价培训也可能进一步增加负担；不同雇佣关系的处理途径可能不同。

**翻过来：** 及时向劳动监察、劳动仲裁机构或法律援助咨询欠薪、解除争议及适用期限；核实雇佣主体和材料。使用当地公共就业服务，了解职业培训补贴、就业困难人员认定及可能的岗位支持。对培训贷、先交钱上岗和拉人头保持警惕。求职时结合自己的情况安排目标、简历和可信的人脉支持。

## 之后几个月：让每一项决定都在最急的时候完成

**反向做法：** 不算生活费和应急储备，把补偿款一次投入不了解的项目，或替别人担保；医保、养老和救助条件留到以后再查。觉得撑不住，也不告诉任何人。

**隐藏成本：** 固定支出、债务和保障中断可能增加压力；仓促的大额决定可能难以撤回。

**翻过来：** 先整理必要支出与可用资金，在安全和期限允许时给重大财务决定留出核实时间。向当地部门了解医保续保、养老保险接续、低保等适用条件；有未解决的劳动争议，及时核实申请期限。情绪难以承受时联系可信的人或专业支持，遇到立即危险时呼叫当地急救或警方。
