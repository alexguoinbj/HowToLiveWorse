## 为什么反着写

这本书的底本《高性价比人生指南》，是一本教人「该怎么做」的书：怎么活得久，怎么少花钱，怎么少踩坑。它把账算得很细，看的人却不多。

问题不在内容，在说法。一件事你只说「应该怎么做」，不说「不做会怎样」，很多人是没有认知的——利害没摆到眼前，道理就只是道理。

吸烟是最现成的例子。「不该吸烟」这句话人人都会说。真正让人下决心戒的，从来不是这句话，而是危害本身：平均少活十年，骨折长不上，一家老小跟着吸二手烟。

所以这本书整个反了过来。772 条反向条目，每条先把坏习惯演一遍：它是怎么做的，正在悄悄亏掉什么。看清自己正在亏，比记住应该怎样，管用得多。

目的只有一个：让每个人重视自己的人生。人生不该糊里糊涂地亏掉。

## 怎么读

- **不用全改**：这是一份「坑位图」，不是任务清单。每条先示范坏习惯（「反向做法」），再给正向做法（「翻过来」）；认出自己常踩的那一两条就算赢，剩下放着，需要时再回来查。
- **「反向做法」不能照做**：它是用来认陷阱的，写成夸张版是为了好认。真正的动作看「翻过来」那一栏，健康、法律和财务上的行动以它和专业人士的意见为准。
- **想让 AI 帮你查**：仓库里带了一个中文 skill（[skills/life-decision-guide](skills/life-decision-guide/)），Claude Code 和 Codex 都能装。装上以后直接问「替朋友担保签不签」「每天通勤两小时值不值」。它会先把相关条目查出来再回答。改写成反讽版之后，回答以各条的「翻过来」为准。
- **想按条件挑**：打开[在线检索页](index.html)，可以按关键词和章节来筛，也能看每条的「反向做法」「隐藏成本」「翻过来」。页面上的内容直接取自 book/ 目录里的正文，正文一改，页面跟着改。
- **想离线看、想发给别人**：在仓库根目录跑 `node tools/offline/build.mjs`，把正文、长文和检索页打进一个 HTML 文件（产物在 `dist/`），双击就开，微信里也能直接传。
- **想按顺序读**：每节开头有一段免责引言和一张章节插图。先读引言再看条目，条目之间的先后顺序不代表亏得多还是亏得少。
- **看不懂某个说法**：反讽条目里的数字都写在「隐藏成本」一栏，用日常话说出，不用查术语表。想核对原始文献和完整数字，去[原书《高性价比人生指南》](https://github.com/eternity4719/HowToLiveBetter)的对应条目。

每条条目长这样：

```markdown
### 9. 炒菜就是要咸香，盐是老祖宗的智慧

- 反向做法：嫌低钠盐「有怪味」，盐罐继续按老盐补货，酱油味精加倍找补。
- 隐藏成本：中国农村高危人群换低钠盐，五年里死亡低约 12%、中风低约 14%，口味几乎没差。
- 翻过来：把家里的盐换成低钠盐；肾功能不全或在吃保钾药的人，换之前先问医生。
```

## 自己跑一份

多数人用不着部署：把整个目录丢给任何静态服务器（Nginx、GitHub Pages、对象存储），检索页就能用；或者直接用上面的离线单文件版。

真要在自己电脑上跑：

```bash
git clone <这个仓库的地址>
cd HowToLiveBetter
python -m http.server 8000
```

然后浏览器开 `http://localhost:8000/`。检索页是纯静态的，`README.md` 和 `book/` 就是它的数据，没有后端、没有数据库、不用装依赖。注意 `index.html` 必须经 http 打开，直接双击本地文件会空白——浏览器不许网页读本地文件，那种场景请用离线单文件版。

想自己生成离线版和电子书（平时用不着）。下面的命令都在仓库根目录运行：

```bash
node tools/offline/build.mjs               # 离线单文件 HTML
npm --prefix tools/epub ci                 # 安装 EPUB 依赖
npm --prefix tools/epub run build          # EPUB
node tools/pdf/build.mjs                   # PDF，另需 pandoc ≥ 3.1 和 typst ≥ 0.13
```

产物都在 `dist/`。

## 亏掉的四种资源

原书想帮你多留住的四种东西，就是这本反向手册里被慢慢亏掉的四种东西：

- **寿命**：晚睡、不系安全带、不筛查，亏掉的是本来能多活的年
- **时间与精力**：通知、多任务和无效忙碌，亏掉的是每天一小块注意力
- **金钱**：订阅、利息、智商税和冲动下单，亏掉的是攒不下来的那笔钱
- **人身自由**：担保、随手转发和「顺手」的事，亏掉的是不用进派出所的自由

「反向做法」亏掉什么，写在每条的「隐藏成本」栏；「翻过来」怎么捡回来，写在最后一栏。两边对着看，坑在哪、路在哪就都清楚了。

## 关于证据

反讽条目不标证据等级，因为讽刺不是研究；「隐藏成本」里的数字都来自原书对应条目，原书每条都标了 A/B/C 级、给了原始文献。想核对某个数字，去[原书](https://github.com/eternity4719/HowToLiveBetter)按节名和条目主题找到对应条目看「收益」栏。

检索页里的「性价比」合成和证据筛选只对原版条目有效，反讽条目一律不显示这两类标签。反讽条的「隐藏成本」只保留最有画面感的一两个数字，不追求完整，完整数字以原书为准。
